# 🌀 OXiDrive – The Next Evolution of Servo Motors  
### **BLDC Smart Servo System • FOC Controlled • Encoder Feedback • Plug-and-Play Simplicity**

---

## 🔥 Overview

**OXiDrive** is a next-generation actuator designed to replace outdated hobby servo motors with a **high-performance BLDC + FOC + Encoder** system that is just as easy to use as a normal servo.

If you can control an MG996R, you can control OXiDrive —  
but now you get **smoothness, torque, precision, and durability** at a whole new level.

OXiDrive is built for:
- Hexapods  
- Quadrupeds  
- Humanoids  
- 6-DOF arms  
- Animatronics  
- Campus robotics  
- Research & rapid prototyping  

This is the actuator Indian robotics has been missing.

---

# 🚨 Why OXiDrive Exists

Students and makers in India are stuck using old hobby servo motors that:
- jitter  
- stall  
- burn easily  
- cannot handle sudden torque  
- move slow  
- and limit every advanced robot idea  

Meanwhile, modern robots use **BLDC motors with FOC and encoders** —  
but these systems cost **₹50,000–₹1,00,000** when imported,  
and are **not available or taught** in most campuses.

**OXiDrive bridges that gap.**  
It brings real robotics actuator technology to every maker and student, at an accessible cost.

# ⭐ Key Features

### 🔧 **Modern Hardware**
- High-torque BLDC motor  
- Magnetic encoder (AS5600 / AS5048)  
- STM32-based FOC controller  
- Optional planetary gearbox  
- Standard MG996R-style footprint  

### ⚙️ **Smart Control Modes**
- Position control (servo mode)  
- Velocity control (motor mode)  
- Torque control (robotics mode)  

### 🧠 **Intelligent Firmware**
- Field Oriented Control (FOC)  
- Auto-calibration  
- Stall + impact protection  
- Soft-start + soft-stop  
- Smooth high-resolution movement  

### 🔌 **Easy Interfaces**
- PWM (servo-style plug-and-play)  
- UART (advanced control)  
- CAN bus (future release)
